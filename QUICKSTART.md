# 🚀 Démarrage Rapide - Admin TechNova RDC

## ⚡ En 5 Minutes

### 1. Accédez à l'Admin
```
Visitez: http://localhost/admin-login.html
Mot de passe: admin2025
```

### 2. Changez le Mot de Passe
1. Allez dans **Paramètres**
2. Entrez votre nouveau mot de passe
3. Cliquez **Enregistrer**

### 3. Ajoutez un Produit
1. Onglet **Produits** → **Ajouter**
2. Remplissez les champs
3. Cliquez **Ajouter le produit**

### 4. Visualisez les Commandes
1. Onglet **Commandes**
2. Voyez toutes les commandes
3. Changez le statut si nécessaire

### 5. Gérez les Utilisateurs
1. Onglet **Utilisateurs**
2. Voir la liste
3. Supprimer si nécessaire

## 🎯 Tâches Courantes

```

```

```
Produits → Modifier → Mettre à jour → Sauvegarder
```

### Supprimer un Produit
```
Produits → Supprimer → Confirmer
```

### Voir les Commandes
```
Commandes → Liste complète avec tous les détails
```

### Exporter les Données
```
Paramètres → Exporter les données → Télécharger CSV
```

**Mot de passe oublié?**

Récupérez depuis le dernier export CSV

Effacez le cache du navigateur (Ctrl+Shift+Suppr)
